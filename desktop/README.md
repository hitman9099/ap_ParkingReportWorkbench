# 停车报表工作台

在 Windows 10/11 x64 双击 ANPING.exe，打开「停车报表工作台」后使用以下流程。

1. 点击「验证浏览器」。会话失效时，程序打开利民停车管理平台的登录窗口。在平台页面输入账号密码并手动完成验证。
2. 选择 .xlsx 台账，填写统计起止日。台账需要有「地块名称」和「月总停车时长（小时）」两列。程序按台账地块逐个匹配平台项目。
3. 选择输出目录和并行车场数。输出目录起始为便携 EXE 所在目录。每次运行按日期范围创建子目录，同一范围重复运行时使用顺序后缀。并行车场数可选 1 至 4，同一车场的多个通道依次处理。
4. 点击「开始导出」。程序将出入状态留空，对每个可选入场通道查询、导出，并核对日期、车场、通道和条数。运行期间可查看日志、车场进度、通道数和记录数。
5. 在「历史记录」打开生成的台账、通道汇总文件或输出目录。结果包括各通道原始 Excel、核验汇总、更新版台账和请求统计。部分完成的任务会标明待处理地块和原因。「继续未完成」会沿用同一任务目录，复用已完成报表。

「查询规则与数据来源」显示平台查询、报表下载菜单，以及当前输出目录和原始报表保存位置。

「请求统计」记录本次所选并行数、实际参与的线程数、同时处理的车场峰值、从浏览器上下文开始监听到导出结束的 HTTP 和 API 次数与并发峰值，以及包含本地 Excel 汇总的任务耗时。

「新建导出」从空白台账、日期和任务进度开始，沿用已设置的输出目录和并行车场数。已生成的文件和未完成任务可在「历史记录」查看。运行中的任务可从侧栏返回查看进度。

任务结束时会弹窗提示结果。「已完成（有问题）」表示本次执行已经结束，存在未匹配或未导出的车场、报表核验、台账生成等问题。原因可以在任务进度、结果弹窗和「历史记录」中查看。

台账时长按有效出场记录的报表分钟累计，再换算为小时，显示两位小数。未形成时长的入场记录、缺失字段和同订单号的重叠记录会按实际情况注明。重复订单的建议扣减列在「最终汇总」，作为核对依据。输入台账作为源文件保留。

## 从源代码构建

构建环境需要 Windows x64、Node 与 npm，以及项目根目录的 Python 虚拟环境，包含 Scrapling、Patchright、openpyxl、lxml 和 PyInstaller。

在 desktop 目录运行 npm ci，再运行 .\build.ps1。便携 EXE 位于 dist 目录，其中已包含运行所需的组件和浏览器。
